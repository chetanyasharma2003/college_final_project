🔧 PRODUCTION INFRASTRUCTURE
═══════════════════════════════════════════════════════════════════════════════

MIDDLEWARE STACK:
  1. Request Timeout (30s) → Prevents hanging connections
  2. Health Check → Database connectivity every request
  3. Response Validation → Consistent JSON structure
  4. Deduplication → Prevents duplicate API calls (1s window)
  5. Circuit Breaker → Fails gracefully after 3 DB errors
  6. Rate Limiting → 10,000 req/15min dev, 100 prod
  7. Helmet Security → XSS, clickjacking protection
  8. CORS Configuration → localhost:3000, 5173, 5174, 5175

ERROR HANDLING:
  ✅ Unique error IDs (ERR_timestamp_randomId)
  ✅ Stack traces (dev only, hidden in production)
  ✅ Retry flags for transient failures
  ✅ Graceful degradation on circuit breaker open

   • Endpoint: GET /api/v1/ml-analytics/patterns/{kpiId}

   • Health Score: Based on KPI status distribution

   • Risk Scoring: (critical×3 + at_risk×1 + on_track×-0.5)

   • Distribution: Shows critical, at-risk, on-track counts
   • Endpoint: GET /api/v1/ml-analytics/risk-kpis/{schemeId}
